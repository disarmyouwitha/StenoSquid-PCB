# Package-E assembly model

The WSON-8 8 × 6 mm model is adapted from the local Rev D model. The orthogonal body and terminals are expanded to the selected Winbond package-E drawing; the exposed pad remains 3.4 × 4.3 mm and maximum body height remains 0.8 mm. The model represents the package envelope for assembly previews and STEP, with simplified terminal and mould details.
